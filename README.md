# Kubernetes Practice

## Overview

This repository contains hands-on Kubernetes practice designed for DevOps learning. The goal is to understand Kubernetes concepts through practical demonstrations, production-style scenarios, and interview-focused explanations.

---

## Environment

- Windows 11
- WSL2 Ubuntu
- Docker
- Minikube
- kubectl
